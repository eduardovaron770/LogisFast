# LogisFast - Prototipo Web SPA

Maquetación de la interfaz gráfica interactiva en HTML, CSS y JavaScript (Single Page Application).
Evidencia: GA5-220501095-AA1-EV04.

## Tecnologías
* HTML5
* CSS3 (Paleta estricta Dark Mode y Responsive Design)
* Vanilla JavaScript (ES6)

## Arquitectura Base (Fases 1, 2 y 3)
* `index.html`: Caparazón principal que contiene las 12 vistas del sistema.
* `styles.css`: Variables globales y estilos modulares.
* `app.js`: Lógica de enrutamiento local nativo y simulación de base de datos (localStorage).

## 🚀 Credenciales de Prueba (Testing)
Para navegar por los diferentes módulos de la aplicación, utiliza los siguientes datos en la pantalla de **Login** (la contraseña puede ser cualquier texto):

* **Acceso Administrador:**
  * **Usuario:** `admin`
  * **Dirige a:** Dashboard de control y asignación de envíos (Desktop).

* **Acceso Repartidor:**
  * **Usuario:** `repartidor`
  * **Dirige a:** Módulo operativo, rutas, escáner simulado y reportes (Mobile-First).

* **Acceso Cliente (Rastreo):**
  * **Usuario:** *(Cualquier otro nombre)* o directamente desde el botón "Rastrear un envío".
  * **Dirige a:** Consulta de guías y línea de tiempo pública.
