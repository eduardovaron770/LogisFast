# LogisFast - Prototipo Web SPA

Maquetación de la interfaz gráfica interactiva en HTML, CSS y JavaScript (Single Page Application).
Evidencia: GA5-220501095-AA1-EV04.

## Tecnologías
* HTML5
* CSS3 (Paleta estricta Dark Mode)
* Vanilla JavaScript (ES6)

## Arquitectura Base
* `index.html`: Caparazón principal y contenedores de las 12 vistas.
* `styles.css`: Variables globales y estilos de componentes.
* `app.js`: Lógica de enrutamiento local y simulación de base de datos (localStorage).
